# Muto Agent Skills
Skills and workflows by [Muto](https://muto.ai) that help AI understand you and work with you.

## Your personal brand
Build a living collection of your stories, goals, experience and preferences, then use it with AI to create work that sounds like you. Start with a warm welcome and a progressive interview. Develop useful assets early and improve them through use.

The Personal Brand skill includes a living knowledge-base template, interviewing guide, source-based voice guidance, 22 asset template recipes, a presence roadmap, progress tracking, Fuel experiences and a local visual workspace.

**Current version: 0.6.3 · Early pilot release**

## Download and start
1. [Download the Personal Brand skill ZIP](downloads/personal-brand-system-v0.6.3.zip?raw=true). Extract it on your computer.
2. Open `personal-brand-system/README.md` for getting-started instructions.
3. Open `personal-brand-system/assets/dashboard/PB-personal-brand-dashboard.html` in your browser to explore a clean example. No server is needed for viewing.
4. Give your AI the skill folder if it supports skills, or share `SKILL.md` and `references/kickoff-guide.md` in the conversation. Other referenced files can be supplied as needed.

Start with this message:

> Help me develop my personal brand using this skill. Start with a warm welcome, explain how I can use it for everyday work, and offer the visual workspace with opening instructions. Ask one question at a time. Work in a separate personal copy. If you cannot save files, give me updates I can save and tell me which supporting files you need.

## Your files and your control
This repository contains only the reusable standard and a clean example. Keep your personal knowledge, answers and generated assets in a separate private folder outside this repository. You choose what to share with your AI platform and review anything before it becomes public.

The files and workspace can live locally. External AI processing follows your chosen platform's settings; the skill does not make all AI execution local. This package is freely available. AI platform costs may apply. Native skill loading, file saving and supported uploads vary by platform. File-capable environments can initialize your personal copy and rebuild the workspace; the included helpers require Python for these operations. Plain chat can guide you and produce proposed updates for manual saving.

## Pilot feedback
Tell us what helps, what feels too deep and what does not sound like you. [Open an issue](https://github.com/muto-labs/agent-skills/issues) with feedback about the standard. Do not post private stories, customer information or personal knowledge-base files in public issues.

Package checks and interface checks have passed locally. Beginner usability, timing and compatibility across AI platforms continue to be evaluated. The skill is a living approach that improves through feedback.

## Updating your workspace
Your AI saves the source files and rebuilds the workspace. You then reload the open HTML page. Reloading alone cannot rebuild it. Use Update my view next to See what's next for a request to copy to your AI, opening instructions and a Reload saved view button. A temporary preview is not a public website or a substitute for a saved handoff.

## Existing users: update safely
Download the new standard separately. Do not extract it over your personal folder. Follow [the update guide](skills/personal-brand-system/references/update-guide.md): preview, backup, preserve personal files and merge customized conflicts before rebuilding and reloading.

Version 0.6.3 adds a gentle two-track visual start: reuse existing materials or choose a minimal working look. It is introduced when design is relevant, with room to defer and improve through use. Earlier releases add source-based voice and factual integrity controls.
