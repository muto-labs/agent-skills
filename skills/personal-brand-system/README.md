# Personal Brand System — start here
Version 0.6.8 | Early pilot release

Version 0.6.8 corrects the completed-foundation display. Once all initial items are resolved or explicitly not applicable, the dashboard shows Foundation complete and reminds you to keep growing through use and feedback. This does not mark lifelong brand development complete.

Build a personal brand you can use with AI and improve over time. No previous branding experience or polished answers required.

## Start with your favorite AI
1. Keep this standard folder as a clean master. Work in a separate personal copy.
2. If your AI supports skill folders, load this package using that tool's supported method. Otherwise attach SKILL.md and references/kickoff-guide.md, then provide other referenced files as needed. Upload limits and file-writing support vary by tool.
3. Send the message below. The AI should orient you briefly and ask one question at a time.

> Help me develop my personal brand using this Personal Brand System. I'm new to this. Start with a warm welcome and offer the visual dashboard with clear instructions for opening and using it. Explain how I can use this with AI for everyday work, and ask me one question at a time. Create my personal copy and dashboard if you have file access. If you cannot save files, provide updates I can save and tell me which supporting files you need. Do not claim changes are saved when they aren't.

Use an AI environment with local file access to initialize the full package and keep the dashboard updated automatically as part of each saved session. Plain chat can guide you and draft assets, but saving files and rebuilding the dashboard may need manual help. The existing HTML dashboard opens locally without Python; its rebuild helpers require Python.

## Use it as you progress
Bring your personal copy back to your AI for a real task: “Using my personal brand, help me prepare for a customer conversation.” Review the result and proposed knowledge updates. Keep the latest copy; a new chat or another AI will need that context again unless its supported setup retains it.

Your knowledge base stores your goals, stories, experience and preferences. Your skill provides instructions and templates for using them. They grow through use; you do not need to finish onboarding before creating useful work. Review everything before making it public.

A progressive interview, living knowledge base, progress and quality guidance, asset template catalog, presence roadmap, Fuel amplifiers, maintenance workflow and local dashboard. The standard contains no Customer Zero personal data.

## See the interface first
Extract this package, then open `assets/dashboard/PB-personal-brand-dashboard.html` in your browser. Click Start here for opening instructions and orientation. This is a clean example; your personal copy will have its own dashboard.

## Keep the visual workspace current
Ask your AI to save your files and rebuild the workspace, then reload the browser page. The visible Reload saved view button only reloads the HTML; it cannot rebuild it. Keep the whole extracted package and a private personal copy. If your AI cannot write or run files, ask for explicit manual saving and rebuilding instructions. A preview link is not the same as a saved file or public website.

## Already have a personal package?
Do not replace your personal folder. Follow [safe update instructions](references/update-guide.md): separate download, preview, backup, preserve customizations, rebuild and reload.
