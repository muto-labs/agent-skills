# Visual direction
ID: visual-direction | Version: 0.1.0
Audience/use: Design work.
Required inputs: Personality; preferences; context; existing assets; rights.
Optional inputs: audience-specific preferences and verified examples.
Length guidance: Brief plus reference inventory.

## Generate
Read relevant KB records and voice guide. Ask only for material gaps; if unavailable, mark them visibly in the draft. Choose disclosure-appropriate proof. Follow this structure flexibly:
Desired feeling → imagery → colors/typography → layouts → accessibility → rights.
