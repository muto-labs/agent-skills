# My purpose
ID: purpose | Version: 0.1.0
Audience/use: a leader's standalone purpose statement and consistent reuse across their brand.

## Generate
Use the leader's supplied or explicitly approved wording. Read the canonical language record purpose in references/integrity-register.json. If a statement already appears on the overview, ask which version to standardize only when unclear; never regenerate an approved purpose merely to make another asset. Propose wording when none exists, label it draft and review it with the leader.

Create a separate leader-prefixed, versioned output. The accepted statement must exactly match purpose.exact_text. Use scripts/render_asset.py with {{language:purpose}} for an approved record, or follow the same exact-text method manually. Record language ID/version and leader decision. Never include tenets inside this purpose asset. Keep explanation and provenance separate from the reusable statement.

## Approval and maintenance
Only explicit approval makes a proposed purpose accepted-for-reuse. Drafting, split requests and general positive feedback about the system do not approve new wording. The dashboard uses the approved canonical statement. If the purpose changes, version the decision and review dependent assets; do not silently rewrite accepted bios or histories.

## Validate
Standalone asset, register and overview agree exactly. No assumed religious beliefs or inferred motives. An accepted purpose does not approve personal tenets or external publishing.
